# ChatApp - A Realtime Chatting Application

## Introduction
   
   ChatApp is an online Live Chatting platform where people can connect with each other by using their mail id. It is designed in such a way that people can exchange texts, images and videos. It is very user friendly and easy to get started with

   ## Techstacks Used

   - Front End: React, Tailwind css.
   - Back End : Node.js, Express
   - Database: Mongdb(Mongoose)
   - Other Tools: Docker, socket.io, clerk
